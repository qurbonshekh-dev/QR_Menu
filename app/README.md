# app

React + Vite + TypeScript фронтенд QR-меню.

Документация проекта — в корне репозитория: [README.md](../README.md),
полный контекст для ИИ-ассистента — [CLAUDE.md](../CLAUDE.md).

```bash
npm install
npm run dev      # дев-сервер (доступен и по локальной сети — для теста с телефона)
npm run build    # tsc -b + vite build
npm run lint     # oxlint
```

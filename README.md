# Food

Монорепозиторий ресторанной платформы: гостевое QR-меню, приложение официанта и экран кухни
на общей дизайн-системе. React + Vite + TypeScript, npm workspaces.

**Живые версии:**

- Гостевое меню — https://qr-menu-pi-sage.vercel.app
- Официант — https://foodwaiter.vercel.app
- Кухня — проект Vercel ещё не заведён

Особенность проекта — дизайн-система существует одновременно в коде и в Figma,
компонент к компоненту, токен к токену.

## Запуск

```bash
npm install            # один раз на весь монорепозиторий
npm run dev            # гостевое меню, порт 5173
npm run dev:waiter     # официант, порт 5174
npm run dev:kitchen    # кухня, порт 5175
```

Дев-серверы слушают и по локальной сети, поэтому приложение можно открыть на телефоне:
Vite напечатает адрес вида `http://192.168.x.x:5173` — телефон должен быть в той же Wi-Fi.
Правки подхватываются на лету.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build` — тоже из корня, по всем воркспейсам.

## Состояние

| Приложение | Что готово |
|---|---|
| Гость | Весь путь: главная стола → меню → блюдо → корзина → оформление → счёт с чаевыми и делением |
| Официант | Главный экран: смена, чаевые, зал со статусами столов, карточка стола |
| Кухня | Доска тикетов «Новый → Готовится → Готово» с перетаскиванием, all-day и таймерами |

Данных с сервера нет ни у кого: каждое приложение работает на локальном моке за
репозиторием-швом (`menuRepository`, `floorRepository`, `ticketsRepository`). Следующий шаг —
общий контракт данных в Supabase, который эти моки заменит.

## Стол из QR-кода

Номер стола приходит параметром: `/#/?table=7`. Без параметра показывается стол 12.

## Деплой

`git push origin main` — Vercel пересобирает автоматически. На каждое приложение свой проект
Vercel из этого же репозитория, отличаются только Root Directory: `apps/guest`, `apps/waiter`,
дальше `apps/kitchen`.

## Где что лежит

| Путь | Что |
|---|---|
| `apps/guest/` `apps/waiter/` `apps/kitchen/` | Приложения: экраны и свой мок-репозиторий |
| `packages/ui/src/components/` | Дизайн-система: atoms / molecules / organisms |
| `packages/ui/src/tokens/` | Токены: цвета, отступы, радиусы, типографика |
| `packages/domain/src/` | Типы и чистая логика: деньги, склонения, счёт, зал, смена, кухня |
| `artifacts/` | Токены-источник, карта id Figma, отчёт о parity |
| `directives/` | Инструкции пайплайна синхронизации с Figma |
| `docs/tz.md` | Техническое задание на продукт |
| `CLAUDE.md` | Полный контекст проекта для ИИ-ассистента |
